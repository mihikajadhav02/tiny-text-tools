# Sound Assets

This directory should contain the following audio files:

## Required Files

1. **typewriter-key.mp3**
   - Short typing sound (50-100ms)
   - Soft key press sound
   - Used when user types in the text area

2. **typewriter-click.mp3**
   - Slightly longer click sound (100-150ms)
   - More pronounced click
   - Used when user clicks buttons

## Where to Get Sounds

You can find free typewriter sounds from:
- [Freesound.org](https://freesound.org/) - Search for "typewriter"
- [Zapsplat.com](https://www.zapsplat.com/) - Free sound effects
- Record your own with a real typewriter

## Format Requirements

- Format: MP3
- Duration: 50-150ms
- Volume: Normalized, not too loud
- Quality: 128kbps or higher

## Note

The application will continue to function without these files, but sound effects will not play.
